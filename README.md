# my-swim-project

## Описание
Программа для обработки результатов соревнований по плаванию и бегу.

## Как запустить
1. Установи зависимости: `pip install pandas openpyxl`
2. Положи файл `competition_data.xlsx` в папку `data`
3. Запусти: `python main.py`

## Формат входных данных
Excel файл с листом `Результаты`, колонки:
- last_name, first_name, event_name, time_seconds, gender, teams
