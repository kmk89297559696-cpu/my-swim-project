# my-swim-project

## Описание
Программа для обработки результатов соревнований по плаванию и бегу.

## Как запустить
1. Установи зависимости: `pip install pandas openpyxl`
2. Положи файл `competition_data.xlsx` в папку `data`
3. Запусти: `python main.py`

## Формат времени в Excel

В колонке `time_seconds` время указывается в формате `ММ,СС,сс`, где:
- `ММ` — минуты (две цифры, например `00` или `01`)
- `СС` — секунды (две цифры, например `39` или `55`)
- `сс` — сотые доли секунды (две цифры, например `40` или `48`)

Примеры:
- `00,39,40` → 39.40 секунд
- `01,12,09` → 1 минута 12.09 секунд
- `09,50,20` → 9 минут 50.20 секунд

## Формат входных данных
Excel файл с листом `Результаты`, колонки:
- last_name, first_name, event_name, time_seconds, gender, teams
